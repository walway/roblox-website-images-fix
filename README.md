## 🚀 Использование

- Установите [последний релиз](https://github.com/walway/roblox-website-images-fix/releases)
- Распакуйте содержимое сжатой папки
- Запустите `service.bat` от имени администратора
- Выберите пункт `1` (Apply fix)

## 📦 Содержимое

`Apply Fix` - Применить фикс<br>
`Unapply Fix` - Убрать фикс<br>
`Test Connection` - Тестирование соеденения с доменом

## 🔧 Тестирование

### 🟢 С фиксом

Соединение прошло успешно благодаря hosts файлу.

```
Status: Connection successful. tr.rbxcdn.com answered via hosts file rule.
```

### 🟢 Без фикса

Соединение прошло успешно без файла hosts, он не нужен.

```
Status: Connection successful. tr.rbxcdn.com answered via native connection. No hosts file needed.
```

### ❌ Без фикса

Соеденение провалилось, не удалось подключиться напрямую, необходимо добавить домен в файл hosts.

```
Status: Connection failed. tr.rbxcdn.com bypassed the hosts entry.
```
